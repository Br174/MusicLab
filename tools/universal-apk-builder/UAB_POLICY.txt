UNIVERSAL APK BUILDER POLICY

Default APK build path:
1. Diagnose with tools/universal-apk-builder/diagnose.sh
2. Build with tools/universal-apk-builder/run-container.sh when container engine is available
3. Otherwise build with tools/universal-apk-builder/build-apk.sh on an Android-SDK-equipped host
4. Collect APK + SHA256 + ZIP under dist/uab

GitHub is the source/version archive. GitHub Actions is NOT the default APK compiler.
Do not trigger GitHub Actions automatically for APK generation. Use it only when Bruno explicitly requests GitHub Actions.
Do not silently switch to a paid build service. If the free/local builder is unavailable, report the blocker.
