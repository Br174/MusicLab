CHANGE COMPATIBILITY GUARD

WATCHDOG COORDINATION
Watchdog is the single coordinator for progress-health detection and anti-stall intervention. Resume Recovery owns checkpoint continuation, manual-lightning salvage and monotonic recovery-floor reconstruction.

MANUAL LIGHTNING SAVE-THEN-RESUME
When Bruno sends `⚡`, preserve the freshest recoverable material state first, reconstruct the monotonic recovery floor, then classify health and continue safely.

MONOTONIC RECOVERY FLOOR
For the same logical operation, a stale lower checkpoint must not reduce recovery below newer coherent verified progress. Regression requires material invalidation evidence and visible explanation.

FOREGROUND STALL GUARD
Checkpoint risky/backgroundable phases first, prefer persistent execution where safe, otherwise use bounded recoverable segments.

PROGRESS REPORTING
Percentages represent verified completion and are monotonic across same-operation recovery unless invalidated by material evidence.

CHECKPOINT / SINGLE WRITER
Preserve enough state to resume deterministically. Only one writer may act on the same project/repository/ref/resource scope.

NATIVE ENGINE COEXISTENCE
MotorLab must not replace project-native/domain engines.

CENTRAL SYNC
Compare local release against central only at a safe boundary. Never switch release mid active operation.

PLATFORM LIMIT
